A robot band name with a hit-song line, written by a tiny deterministic Python program to `entry.txt` — The Roomba Stones and their hit single "Dust in the Wind (Under the Couch)". Entry for make.fun's "Name the Robot Band" bounty.

## The entry

> The Roomba Stones — hit single "Dust in the Wind (Under the Couch)"

A vacuum-cleaner band named after the Rolling Stones, covering Kansas — and getting stuck under the couch, as Roombas do. The program writes exactly this text (67 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` in the grader sandbox.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
